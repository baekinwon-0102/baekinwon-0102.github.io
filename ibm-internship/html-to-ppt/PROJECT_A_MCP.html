MCP란 무엇인가?

DEFINITION
Model Context Protocol
AI 모델이 외부 도구·데이터·서비스를 표준화된 방식으로 연결하는 오픈 프로토콜
WITHOUT MCP
서비스마다 별도 연동
각 외부 서비스마다 독립 연동 코드 작성 필요 — 유지보수 비용 급증
WITH MCP
단일 인터페이스로 통합
MCP 서버가 제공하는 기능을 확인 후 호출 — 내부 구현 불필요
🔌
USB 규격 비유
USB가 다양한 장치를 하나의 규격으로 연결하듯, MCP는 AI와 외부 서비스를 하나의 인터페이스로 통합합니다.

python-pptx
라이브러리란?

Python으로 .pptx 파일을 직접 생성·편집할 수 있는 오픈소스 라이브러리입니다.

Python-pptx 단점

CONS 01

템플릿 적용 시 깨짐
기존 템플릿에 내용만 수정 시 XML 구조 충돌로 디자인이 깨질 위험 존재

COM 기반 MCP · 이건희  (1/5)

COM이란 무엇인가?

DEFINITION
Component Object Model
Microsoft의 프로세스 간 통신(IPC) 기술. Python에서 PowerPoint 앱을 직접 프로그래밍으로 제어 가능
HOW IT WORKS
win32com 라이브러리
Python win32com.client로 PowerPoint 객체 인스턴스 생성 → 슬라이드·도형·텍스트 직접 제어
KEY ADVANTAGE
PowerPoint의 모든 기능을 코드로 제어
python-pptx가 XML 레벨에서 작동한다면, COM은 PowerPoint 애플리케이션 자체를 직접 조종합니다. 애니메이션·SmartArt·차트 등 모든 기능이 열립니다.

COM 기반 MCP 단점

CONS 01
항상 단조로운 디자인
PowerPoint 기능이 모두 열려있지만 Agent가 실제로 선택하는 기능은 한정적 → 디자인 다양성 부족

프로젝트의
한계점

LIMIT 01
도구 수 과다 — 성능 저하

LIMIT 03
환경 의존성 미해결
COM 방식의 Windows 전용 문제를 근본적으로 해결하지 못한 채 프로젝트를 마무리했습니다.
